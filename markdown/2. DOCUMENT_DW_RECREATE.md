## 8. View Replacement Strategy

### 8.1 Why ลบ `08_views.sql`

AI03 ไม่มี `CREATE VIEW` privilege (Oracle 10gR2 + CONNECT role downgrade). DBA ติดต่อยากใน timeframe → decision: **เปลี่ยน view ทุกตัวเป็น FastAPI endpoint** ที่รัน SQL ตรงๆ

### 8.2 Mapping (Oracle View → FastAPI Endpoint)

ทุก endpoint ใน [`app/api/dashboard_api/dashboard.py`](../app/api/dashboard_api/dashboard.py):

| Oracle View | FastAPI Endpoint | Function | Used by |
|---|---|---|---|
| `V_OEE_DAILY` | `GET /api/analytics/oee-daily?period=` | OEE per (date × line × shift) | Production page (อนาคต) |
| `V_DEFECT_PARETO` | `GET /api/analytics/defect-pareto?period=` | Defect Pareto + count + qty | Quality page (อนาคต) |
| `V_SCHEDULE_ADHERENCE` | `GET /api/analytics/schedule-adherence?period=` | Slippage per batch + status | Scheduling page |
| `V_BATCH_FEATURES` | `GET /api/analytics/batch-features` | ML feature matrix (21 features + 2 targets) | LightGBM trainer |

### 8.3 Trade-offs

**Pros:**
- ✅ ไม่ต้องรอ DBA grant
- ✅ View logic เก็บ collocated กับ API code (Python ฝั่งเดียว)
- ✅ Pareto pct คำนวณฝั่ง client → ไม่ต้องใช้ Oracle window function (10g compat)
- ✅ ไม่ pollute schema ด้วย object ที่ DBA ลำบาก review

**Cons:**
- ❌ View ไม่ reusable นอก FastAPI (เช่น direct SQL*Plus query) — แต่ workflow นี้ทุกอย่างไป through API อยู่แล้ว
- ❌ ML pipeline ต้องเรียก HTTP API แทน raw SQL — แต่ก็ caching ได้ตามปกติ

### 8.4 Future migration

ถ้า DBA grant `CREATE VIEW` ในอนาคต:
1. นำ SQL ใน `_SQL_V_*` constants มาเขียน `08_views.sql` ใหม่
2. Apply via `run_sql_file.py`
3. (Optional) ปรับ endpoint ให้ JOIN view แทน inline SQL

## 9. Encountered Blockers

### 🔴 Blocker 1: `CONTINUE` keyword (RESOLVED)

**Where:** [07_procedure_fact_load.sql:240](../db_module/db_sources/oracle_sql_query/query/07_procedure_fact_load.sql) (เดิม)

**Cause:** `CONTINUE` PL/SQL keyword เพิ่มมาใน 11g R1 — Oracle 10g ไม่มี

**Fix:** Flag pattern (Oracle 10g compat)

```sql
DECLARE v_skip BOOLEAN := FALSE;
BEGIN
    BEGIN SELECT ... INTO ...
    EXCEPTION WHEN NO_DATA_FOUND THEN v_skip := TRUE; END;
    IF NOT v_skip THEN INSERT ... END IF;
END;
```

### 🔴 Blocker 2: `CREATE VIEW` privilege (RESOLVED via decision)

**Cause:** AI03 มีเพียง `CONNECT + RESOURCE` roles. Oracle 10gR2 ลด `CONNECT` เหลือ `CREATE SESSION` เท่านั้น; `RESOURCE` ไม่เคยมี `CREATE VIEW`

**Decision:** Skip Oracle views ถาวร, replace ด้วย FastAPI analytics endpoints (ดู §8)

### 🔴 Blocker 3: JDBC type binding (RESOLVED)

**Where:** `sync_dimensions_from_supabase.py` ตอน insert `STG_MACHINE.install_date`

**Cause:** `OraclePreparedStatement.setObject(int, datetime.date)` ไม่มี overload — ต้อง pass java.sql.Date

**Fix:** เพิ่ม `_coerce()` helper ใช้ `jpype.JClass("java.sql.Date").valueOf(iso)` (pattern เดียวกับ `app/api/dw_api/deps.py:parse_iso`)

### 🔴 Blocker 4: Supabase `machine.is_active` ไม่มี (RESOLVED)

**Cause:** Supabase schema [`01_schema.sql:14-22`](../db_module/db_sources/supabases_sql_query/query/01_schema.sql#L14-L22) ของ `machine` table ไม่มี `is_active` column

**Fix:** Set `'Y'` default ทั้งใน `sync_dim_supabase.py` (DAG) และ `sync_dimensions_from_supabase.py` (CLI)

## 10. Bug Fixes Applied

### 10.1 `run_sql_file.py` — VIEW parsing bug

`_PLSQL_BLOCK_STARTS` มี `"CREATE OR REPLACE "` (มี space) ที่จับ `CREATE OR REPLACE VIEW` พลาด → views ไม่ถูก split ที่ `;` → ทุก view รวมเป็น 1 statement → ORA-00911

**Fix:** ระบุ object type ให้ชัด: `"CREATE OR REPLACE PROCEDURE/FUNCTION/TRIGGER/PACKAGE"`

> ⚠️ Bug นี้แก้ก่อนรู้ว่าต้องลบ 08_views ทั้งไฟล์ — แต่ fix ก็ถูกต้องอยู่ดี (อนาคตถ้ามี view กลับมาจะ parse ถูก)

## 12. Constraints Documented

### 12.1 Oracle Server Constraints

| Constraint | Detail | Workaround |
|---|---|---|
| Version | 10.2.0.3 (2006) | ห้ามใช้ feature 11g+: `CONTINUE`, `LISTAGG`, `JSON_*`, `MERGE ... NOT MATCHED BY SOURCE` |
| `CONTINUE` keyword | ไม่รองรับ | flag pattern: `v_skip BOOLEAN`, `IF NOT v_skip THEN ... END IF` |
| `SEQ.NEXTVAL ใน INSERT...SELECT` | ไม่รองรับ | Cursor FOR-LOOP ([example](../db_module/db_sources/oracle_sql_query/query/07_procedure_fact_load.sql#L46-L66)) |
| NLS_CALENDAR default | `'THAI BUDDHA'` (offset +543) | OracleConnector ALTER SESSION → `'GREGORIAN'` ทุก connection |
| Driver | python-oracledb thin-mode ต้อง 12c+, no ARM64 instant client | JDBC thin: jaydebeapi + ojdbc8.jar + jpype |

### 12.2 AI03 User Privilege Constraints

```
✅ CREATE SESSION/TABLE/SEQUENCE/PROCEDURE/TRIGGER/TYPE
✅ CREATE CLUSTER/INDEXTYPE/OPERATOR
✅ UNLIMITED TABLESPACE

❌ CREATE VIEW                  → workaround: FastAPI endpoints (§8)
❌ CREATE MATERIALIZED VIEW
❌ CREATE SYNONYM / PUBLIC SYNONYM
❌ CREATE USER
❌ ALTER SYSTEM/SESSION ระดับ admin
❌ EXECUTE บน sys packages (UTL_FILE, DBMS_AQ)
```

### 12.3 JDBC + JVM Constraints

| Constraint | Detail |
|---|---|
| `thinLogonCapability=o3` | บังคับ ojdbc8 ให้รองรับ Oracle 10g logon |
| `disableOob=true` | ปิด Out-of-Band breaks |
| `user.language=en, user.country=US` | บังคับ Gregorian + ENGLISH (ป้องกัน Date.valueOf ส่งปี Buddhist) |
| `JAVA_HOME` ใน `.env` | `/opt/homebrew/opt/openjdk@17/...` (host-only); JVM start ครั้งเดียวต่อ process |
| `autocommit=False` | ต้อง commit/rollback เอง |
| `setObject(datetime.date)` ไม่มี overload | ต้องส่ง `java.sql.Date.valueOf(iso)` ผ่าน jpype |

### 12.4 SQL DDL Parser (`run_sql_file.py`)

| Rule | Detail |
|---|---|
| Plain SQL | จบด้วย `;` ที่ท้ายบรรทัด |
| PL/SQL block (BEGIN/DECLARE/PROCEDURE/FUNCTION/TRIGGER/PACKAGE) | จบด้วย `/` บรรทัดเดียว |
| `CREATE OR REPLACE VIEW` | ไม่ใช่ block — split ด้วย `;` ปกติ (post-fix) |
